# 个人简约记账本 APP

## 项目概述

个人简约记账本 APP 是一个面向个人日常收支管理的轻量工具，用于快速记录收入、支出、分类、备注和日期，并通过月度统计帮助用户了解消费结构、预算执行情况和资金流向。

该项目适合作为作品集中的移动端 / 轻量产品项目展示，重点体现从用户需求拆解、数据建模、交互流程设计到本地化存储和统计展示的完整实现能力。

## 项目定位

- 项目类型：个人财务记录工具 / 简约记账 App
- 目标用户：希望快速记录日常收支、复盘消费结构的个人用户
- 使用场景：日常消费记录、收入记录、月度账单复盘、分类统计、预算控制
- 产品风格：轻量、简洁、低学习成本，优先保证记录效率

## 核心问题

很多记账工具功能复杂、入口层级深，用户在真实消费场景中容易因为记录成本过高而放弃。本项目的目标是降低记账动作的摩擦，让用户可以在几秒内完成一笔收支记录，并在月末快速看到钱花在了哪里。

## 核心价值

- 快速记录日常收入和支出
- 按餐饮、交通、购物、住房、娱乐、学习等分类管理账目
- 支持月度收入、支出、结余统计
- 帮助用户发现高频消费类别和异常支出
- 用简洁界面降低持续记账门槛
- 展示移动端产品设计、状态管理、数据建模和统计分析能力

## 功能模块

### 1. 收支记录模块

收支记录模块是 App 的核心入口，强调快速完成记录。

主要字段：

- 类型：收入 / 支出
- 金额
- 分类
- 日期
- 账户或支付方式
- 备注
- 创建时间
- 更新时间

典型流程：

1. 用户点击新增记录；
2. 选择收入或支出；
3. 输入金额；
4. 选择分类和日期；
5. 可选填写备注；
6. 保存后立即回到列表或统计页。

### 2. 分类管理模块

分类管理用于帮助用户按消费场景理解自己的资金流向。

默认支出分类：

- 餐饮
- 交通
- 购物
- 住房
- 通讯
- 保险
- 娱乐
- 学习
- 人情
- 其他

默认收入分类：

- 工资
- 兼职
- 奖金
- 报销
- 理财
- 其他

可扩展能力：

- 自定义分类名称
- 设置分类图标或颜色
- 隐藏不常用分类
- 分类排序

### 3. 账单列表模块

账单列表用于展示按时间排列的收支记录，并支持快速检索和编辑。

展示内容：

- 日期分组
- 每日收入 / 支出小计
- 账目分类
- 金额
- 备注摘要
- 支付方式

操作能力：

- 编辑记录
- 删除记录
- 按月份筛选
- 按分类筛选
- 按收入 / 支出类型筛选
- 按关键词搜索备注

### 4. 月度统计模块

月度统计模块用于帮助用户形成消费复盘。

统计指标：

- 月收入
- 月支出
- 月结余
- 日均支出
- 最大单笔支出
- 支出分类占比
- 收入分类占比
- 近 7 日 / 近 30 日趋势

图表展示：

- 分类占比图
- 月度趋势图
- 每日支出柱状图
- 收支对比卡片

### 5. 预算与提醒模块

预算模块用于辅助用户控制支出，不做复杂理财功能。

能力设计：

- 设置月度总预算
- 设置分类预算
- 展示预算剩余
- 超预算提醒
- 月末账单总结

## 页面结构

- 首页：本月收入、支出、结余和快捷记账入口
- 新增记录：金额输入、类型切换、分类选择、日期和备注
- 账单列表：按日期分组的记录流
- 统计页：月度收支、分类占比和趋势图
- 分类管理：编辑收入 / 支出分类
- 设置页：预算、数据导出、主题和基础偏好

## 交互设计要点

- 新增记录入口常驻，减少记账路径
- 金额输入区域优先级最高，避免表单过重
- 分类使用图标或色块辅助识别
- 月份切换要清晰，便于回看历史账单
- 删除操作需要二次确认
- 空状态应引导用户添加第一笔账
- 图表不追求复杂，优先服务消费复盘
